# Abstract

Large Language Models (LLMs) have demonstrated promising capabilities in software engineering tasks, including automated code generation and unit test generation. However, generating high-quality unit tests for real-world software systems remains challenging due to limited context understanding, complex dependency relationships, and insufficient awareness of software architecture. Existing LLM-based test generation approaches primarily rely on source code as input and often fail to capture architectural knowledge such as component responsibilities, abstraction boundaries, dependency directions, and implementation relationships.

In this paper, we propose an Architecture-Aware Context Engineering framework for LLM-based unit test generation in modular software systems. The proposed approach introduces a structured representation of software architecture knowledge that can be extracted from existing software repositories and transformed into an LLM-compatible context representation. Instead of providing large amounts of raw source code, our framework analyzes software architecture elements, including components, layers, protocols, dependencies, implementations, and testing strategies, and selectively provides relevant architectural context for the target component.

The proposed framework consists of four main stages: architecture extraction, context construction, context enrichment, and context selection. The architecture extraction phase identifies software components and their relationships, while the context construction phase creates a structured architecture model. The enrichment phase adds semantic information such as component responsibilities, mocking strategies, and concurrency requirements. Finally, the context selection phase generates a focused context representation containing only the architectural information required for generating unit tests.

The goal of this research is to investigate whether architecture-aware context engineering can improve the reliability and quality of LLM-generated unit tests compared to traditional code-only prompting approaches. The framework is evaluated through a comparative experimental design between baseline LLM test generation and architecture-aware test generation using metrics including test compilability, correctness, coverage improvement, dependency mocking accuracy, and architectural compliance.

This research aims to bridge the gap between software architecture knowledge and modern LLM-based software engineering tools by introducing an architecture-aware approach for scalable and maintainable automated test generation.
